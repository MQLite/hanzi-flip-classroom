# 汉字奇遇岛 · 识字与组词课堂

适合小学汉语课堂投屏的网页游戏，提供“识字翻翻乐”和“组词小工坊”两种模式。默认使用从六册PDF核对的《汉语乐园》1A–3B题库，新增暨南大学华文学院《中文》（小学，第三版）第一、二册，同时保留新版《中文乐园》课本1–3题库及一至四年级通用示例题。老师操作，学生口头抢答；Three.js 负责立体场景，汉字、词语和句子保持大字显示。

在线课堂：[打开识字翻翻乐](https://mqlite.github.io/hanzi-flip-classroom/)。

## 在线部署

代码仓库：[MQLite/hanzi-flip-classroom](https://github.com/MQLite/hanzi-flip-classroom)。推送到 `main` 后，GitHub Actions 自动测试、构建并部署到 GitHub Pages；也可以在 Actions 中手动运行部署流程。

部署构建使用 `VITE_BASE_PATH=/hanzi-flip-classroom/`，本地开发默认使用 `/`。在线地址和本地地址属于不同来源，题库不会自动迁移：在原地址导出 JSON 后，到新地址导入即可。线上题库仍保存于使用者自己的浏览器，不会写回 GitHub 仓库。

## 启动

需要 Node.js 22.12 或更新的受支持版本。首次运行：

```powershell
cd D:\Repository\hanzi-flip-classroom
npm install
npm run dev
```

在浏览器打开 **http://127.0.0.1:5174/**。之后在同一目录运行 `npm run dev` 即可。端口固定为 5174，若被占用会明确报错，不会偷偷换地址。

构建并查看生产版本：

```powershell
npm run build
npm run preview
```

开发服务和预览服务不能同时占用 5174 端口，先关闭前一个。请始终使用同一个浏览器和上述地址，以便读取自己的题库；直接双击 HTML 文件不是支持的启动方式。

## 上课使用

《中文》（小学，暨南大学华文学院第三版）可在“题库”选择“中文（暨南大学版）”，再选择册数、课次和练习范围。第一册、第二册以及后续第三册、第四册等均归入这一教材系列；册数菜单只列已收录教材。目前已收录第一、二册。两册24课收录285个课次生字（第一册144、第二册141）及805条教材词项（含跨栏目重复、独立词语表和补充读一读栏目）。展开“教材生字与词语”可查看教材原序、拼音及印刷页码。来源范围与逐课数量见[《中文》题库说明](docs/zhongwen-sources.md)。

识字翻牌使用每课全部生字；两个参考词和简单例句是辅助教学内容。组词小工坊直接使用独立保存的完整教材词表，包含此前学过的字组成的词语和短语，不受每道字题两个例词的限制；按2–8个汉字组词，单字在识字翻翻乐中练习。书名号在教材词表中保留，在活字游戏中仅拆内部汉字。句子小火车继续使用原有切分，新《中文》题目可由老师在题库管理中配置例句的手动切分。

已有浏览器题库请点击“补充教材题库”或管理器的“补充缺失教材题”。只追加缺失题目，保留个人题、原有教材题、已改例词例句及已有ID。相同课次生字按教材归属去重，多次补充不会重复添加；导出JSON备份与导入保留新版归属，备份格式仍为schemaVersion 1。

选择题库来源和小组后，让学生看字回答，再翻牌揭晓汉字、拼音和词语，卡片不显示底部例句；句子练习使用句子小火车。《汉语乐园》按原书1A–3B分册、1–12课筛选，支持本课、全册和截至本课累计复习。新版教材可选1A–3B阶段、整个阶段、本课或截至本课累计复习；每册A为第1–6课，B为第7–12课，**A/B是游戏分组，不是新版教材原有分册**。个人 / 通用题库仍按年级选择。选中作答小组，点击答对计分或标记再次练习。每轮最多八个不同汉字，新版每课三个字，《汉语乐园》每课按核心词汇识字范围抽取，结束后可以复习。

《汉语乐园》新增36课、302词条、465道课次汉字题，覆盖355个不同汉字。识字卡展示每字两个辅助例词；题库中的配编例句保留供编辑和句子练习，翻牌时不显示；1A、1B组词工坊直接使用完整教材词表，其他级别沿用现有参考词。句子小火车独立使用课本对话、歌曲和故事选句。逐册数量、PDF页码、读音处理和来源见[PDF题库说明](docs/hanyu-paradise-sources.md)。

新版教材采用出版社现行《中文乐园》（英文版）前三册的官方汉字大纲：36课、108个教学条目、99个不同汉字。例词例句由项目配编，可修改。版本、ISBN、逐课字表及资料来源见 [教材来源](docs/curriculum-sources.md)。

提问时石碑只显示汉字，不显示拼音；揭晓后显示拼音，中央自动按笔画书写，可点击“重播笔顺”再次观看。更多笔画、笔顺控制和已有偏旁部首资料位于默认收起的拓展学习中。全部498个内置汉字提供本地笔顺演示，新增汉字没有对应本地数据时显示文字资料，不生成猜测的笔顺。

快捷键：空格翻牌，左右方向键切换题目。打开管理面板或编辑输入时，课堂快捷键暂停。可切换全屏和简化显示；组词小工坊使用同一盘字块，不按左右方向键换题。

《汉语乐园》1A、1B已按提供课本复核：12课93条核心词项（1A 45条；1B 47条新词及第9课正文复习词“看”）。点击教材说明旁的“查看教材词语”可见词语、拼音和来源页。组词只用本课教材中的2–8字词语，单字继续用于识字翻牌；不会把卡片上的辅助例词混入教材词库。已有题库点击“补充教材题库”可追加第9课“看”的识字题，保留旧题和个人修改。

## 立体识字场景

识字翻翻乐使用草地浮岛主题：岛屿土层、岩石、树木、书本、识字碑和奖励星星均为 Three.js 网格模型。主汉字由本地笔画轮廓挤出为有厚度的字形；拼音和词语仍用清晰的大字呈现；识字翻牌不展示例句，题库中已有例句及小火车设置继续保留。字形加载失败时自动显示文字，设备不支持 WebGL 时可照常翻牌和计分。场景静止时不重复绘制，减少课堂投屏时的 GPU 开销。

答对后得一颗星，镜头沿立体踏石前进到下一座小岛，约两秒后自动换字；最后一题答对后显示本轮总结。过渡期间暂停答题与前后切题，避免重复结算。切换模式会先完成当前题的前进；重新开局会取消旧过渡。简化显示或系统选择减少动态效果时，直接进入下一题，不播放镜头行走。

## 组词小工坊

进入“组词小工坊”，系统从当前题库范围随机预选 **4 个不同的参考词**，将它们拆成单字，打乱后放入左侧木活字槽。每盘可选 2、3 或 4 个词；词数不足时按实际数量开始。重复字保留足够份数，每个字块有固定位置。按顺序选择 2–8 个字，点已选字块可取消，也可撤回或清空。

完成一盘后，只要当前课或阶段还有未收集的参考词，就可直接点击“继续下一盘”。下一盘不会重复已收集词，也不会清空累计得分和成品印版；当前范围的参考词全部完成后，页面会明确提示。

点击“融合印版”后，命中本盘未完成的参考词时，所选字块合成木质词语印版并收入右侧，左侧扣除这些字块，其余字块留在原槽。继续用同一盘的字组词，集齐预选词后结束本盘。

没有命中参考词时，字块停在中央，等待教师判断。“教师判对”会收集一块蓝绿色、标注“教师认可”的印版，同时将原字块还原到左侧；“返回重试”会播放归位动画，不计分。每个新收集的词给提交时的小组加 1 星，同一词在本盘不能重复收集或计分。教师认可的新组合不减少参考词进度，也不消耗字块。

木质桌板、候选活字、排字区和收集到的词语印版都由 Three.js 建模，使用斜视镜头展示桌板与字块厚度。单字与整词印在模型表面，不为词义分别制作模型。窄屏手机自动采用便于触控的字块布局；选择“简化显示”或设备无法使用 WebGL 时，仍可完成选字、判断、重试和收集；遵循系统减少动态效果设置。

参考词来源仍为题库中包含所属目标字的 2–8 个汉字词语，跨题去重后抽取。教师可展开本盘参考词查看。题库修改从新一盘生效；没有有效参考词时，可进入题库管理补充。右侧模型架展示最近八块印版，下方记录保留本盘全部收集结果。

三种模式共用题库，各自保留本轮筛选、组名、得分、进度、拼音开关、选字顺序与收集印版。切换模式不会清空；开始新一轮或修改课堂设置只重置当前模式。**刷新后课堂进度重置，题库仍保存在浏览器中。**

## 句子小火车

《中文（暨南大学版）》第一、二册另收录85条教材选句，覆盖24课，每课2–4条。第一册前六课使用阅读儿歌、谜语，后六课及第二册同时选用课文与阅读；按全册、本课或截至本课累计练习，课堂显示栏目、篇名和教材页码。节选保留原文字词并注明标点调整，选句清单见[《中文》小火车来源](docs/zhongwen-sentence-train-sources.md)。这些句子独立于识字卡例句加载，不改写已保存题库，也无需重新恢复默认题库。

《汉语乐园》1A–3B改用逐页核对的课本对话、歌曲和故事原句，显示栏目、篇名和教材页码，选句及标点处理见[原句来源](docs/hanyu-paradise-sentence-train-sources.md)。1A第3课只有数字认读，页面引导切换识字或选择其他课，不用配编句填充。老师已保存的有效手工切分继续生效；与教材句重复时优先采用老师的切分，且保留同课教材出处。

点击“句子小火车”，按当前教材、阶段和课次筛选句子。新版《中文乐园》103道和通用题40道仍使用原有配编例句及人工切分，合计133个不同例句，旧覆盖审计保存在[历史记录](docs/sentence-train-content-coverage.md)。个人题库中有有效手动切分的例句也可参与。每轮最多八句，按完整例句去重，数量不足时按实际句数开始。教材选句独立加载，无需恢复默认或覆盖已保存题库。

小站、草地、月台、树林和铁路共处一个立体场景。点击候车区词语，车厢从固定停车位驶入轨道，从左到右接在火车头后；点击轨道车厢可放回，也可撤回或清空。每个候车位固定，重复词语是不同车厢。接齐后“发车”会检查参考顺序：匹配时给提交时的小组加一星，在统一的三维小站中转动车轮、冒出蒸汽，伴随升空绽放的烟花，约 2.4 秒后自动换句。没有匹配时保留排列，可继续调整或请老师点击“老师判对”；教师接受的实际句子会记入旅程记录，不会改写题库参考答案。

“看看参考句”揭晓后仍可练习，但不会自动奖励；每次排齐并检查后，由老师判对才记分。每句最多记一星。“再练一次”加入复习并锁定本题，点击“下一句”继续；直接跳过记为未作答。回看可见原排列和结果，不能再次得分。总结后的复习只包含明确标记再练的句子。

真实 Three.js 车头、车厢、车轮和连接件同步呈现排列。窄屏中候车区换行，轨道可局部横向滚动并显示新加入的车厢。简化显示、WebGL 不可用或上下文丢失时，HTML 车厢保留相同功能。键盘可聚焦词语按钮并按空格选择；页面空白处空格发车，左右方向键导航。减少动态效果和页面隐藏时安全完成一次发车，不重复计分。

题库管理中的“句子小火车设置”显示已有内置或手动切分。勾选“启用手动切分”，用 `/` 分隔 2–7 节词语，每节 1–6 个汉字，全句正文最多 28 字；句尾使用 `。`、`？` 或 `！`。标准词语连接后必须与例句一致。其他参考顺序每行一条，最多五条，必须使用相同词语及次数。无效草稿不能保存；“清除手动切分”会重新尝试内置映射。内置映射同时匹配原题 ID 和完整例句，修改例句后不会套用旧切分。

备份仍使用 `schemaVersion: 1`，可选字段 `sentenceTrain` 包含 `tokens`、`punctuation` 和 `alternatives`；旧备份无需此字段也可导入。提供无效切分的导入会整体拒绝。三个模式分别保留筛选、组名、选中小组、排列和结算；题库修改从下一轮生效，刷新会重置课堂进度。

## 编辑、保存和备份

题库管理可以按年级、教材阶段筛选，搜索、添加、编辑或删除题目。通过校验的编辑会自动保存在当前浏览器；注意界面显示的保存状态。不完整草稿不会覆盖上次有效题目。教材归属会显示在题目上，修改汉字或年级时转为个人题，避免误标官方范围。

**已有用户升级：** 点击课堂提示中的“补充教材题库”，或管理器的“补充缺失教材题”。只追加缺失教材题，保留全部已有题目及个人修改，不需恢复默认。首次访问默认选择《汉语乐园》，初始化906道题（465道《汉语乐园》、108道新版《中文乐园》、285道《中文》、48道通用题）。

可以导出 JSON 题库备份，在另一台电脑导入。导入会先检查和预览内容，确认后整体替换。恢复默认题库也会移除个人修改，操作前可先导出。

**题库长期保存；课堂分组、得分和答题进度在刷新后重置。** 已开始的一轮使用题目快照，备课修改从下一轮生效。清理浏览器网站数据或使用无痕窗口可能丢失本地题库，请定期导出。跨设备不会自动同步。
