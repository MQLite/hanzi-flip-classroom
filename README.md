# 汉字奇遇岛 · 识字与组词课堂

适合小学汉语课堂投屏的网页游戏，提供“识字翻翻乐”和“组词小工坊”两种模式。内置新版《中文乐园》课本1–3题库，以及原一至四年级通用示例题。老师操作，学生口头抢答；Three.js 负责立体场景，汉字、词语和句子保持大字显示。

在线课堂：[打开识字翻翻乐](https://mqlite.github.io/hanzi-flip-classroom/)。

## 在线部署

代码仓库：[MQLite/hanzi-flip-classroom](https://github.com/MQLite/hanzi-flip-classroom)。推送到 `main` 后，GitHub Actions 自动测试、构建并部署到 GitHub Pages；也可以在 Actions 中手动运行部署流程。

部署构建使用 `VITE_BASE_PATH=/hanzi-flip-classroom/`，本地开发默认使用 `/`。在线地址和本地地址属于不同来源，题库不会自动迁移：在原地址导出 JSON 后，到新地址导入即可。线上题库仍保存于使用者自己的浏览器，不会写回 GitHub 仓库。

## 启动

需要 Node.js 22.12 或更新的受支持版本。首次运行：

```powershell
cd D:\Repository\hanzi-flip-classroom
npm install
npm run dev
```

在浏览器打开 **http://127.0.0.1:5174/**。之后在同一目录运行 `npm run dev` 即可。端口固定为 5174，若被占用会明确报错，不会偷偷换地址。

构建并查看生产版本：

```powershell
npm run build
npm run preview
```

开发服务和预览服务不能同时占用 5174 端口，先关闭前一个。请始终使用同一个浏览器和上述地址，以便读取自己的题库；直接双击 HTML 文件不是支持的启动方式。

## 上课使用

选择题库来源和小组后，让学生看字回答，再翻牌揭晓拼音、组词和例句。新版教材可选1A–3B阶段、整个阶段、本课或截至本课累计复习；每册A为第1–6课，B为第7–12课，**A/B是游戏分组，不是新版教材原有分册**。个人 / 通用题库仍按年级选择。选中作答小组，点击答对计分或标记再次练习。每轮最多八个不同汉字，单课默认三个字，结束后可以复习。

新版教材采用出版社现行《中文乐园》（英文版）前三册的官方汉字大纲：36课、108个教学条目、99个不同汉字。例词例句由项目配编，可修改。版本、ISBN、逐课字表及资料来源见 [教材来源](docs/curriculum-sources.md)。

笔画、笔顺和已有偏旁部首资料位于默认收起的拓展学习中。全部131个内置汉字提供本地笔顺演示，新增汉字没有对应本地数据时显示文字资料，不生成猜测的笔顺。

快捷键：空格翻牌，左右方向键切换题目。打开管理面板或编辑输入时，课堂快捷键暂停。可切换全屏、拼音提示和简化显示。

## 组词小工坊

进入“组词小工坊”，在木活字备选栏中按顺序选择汉字，拼成包含目标字的词语。备选栏包含干扰字，也会提供“爸爸”一类叠词所需的多个相同字块。每个木字块可选一次，点已选字块可取消，也可撤回最后一字或清空。

点击“融合印版”后，系统按本题题库中的有效参考词判断。匹配成功时，字块合成一整块木质词语印版，移到旁边的印版架；当前小组得一颗星，动画结束后自动进入下一题并生成新备选栏。未匹配时，字块会晃动散落并归位，留在当前题继续尝试，不记分。“未匹配”只表示没有命中本题参考词，不表示这个组合一定不是汉语词语。

木质桌板、候选活字、排字区和收集到的词语印版都由 Three.js 建模，使用斜视镜头展示桌板与字块厚度。单字与整词印在模型表面，不为词义分别制作模型。窄屏手机自动采用便于触控的字块布局；选择“简化显示”或设备无法使用 WebGL 时，仍可完成选字、判断、重试和收集；遵循系统减少动态效果设置。

每题的有效参考词为包含目标字的 2–8 个汉字。题库管理修改答案后，从新一轮生效。没有有效参考词时，请在题库管理中补充。明确标记“再练一次”的题目进入复习，直接跳过记为未作答。

两种模式共用题库，各自保留本轮筛选、组名、得分、进度、拼音开关、选字顺序与收集印版。切换模式不会清空；开始新一轮或修改课堂设置只重置当前模式。**刷新后课堂进度重置，题库仍保存在浏览器中。**

## 编辑、保存和备份

题库管理可以按年级、教材阶段筛选，搜索、添加、编辑或删除题目。通过校验的编辑会自动保存在当前浏览器；注意界面显示的保存状态。不完整草稿不会覆盖上次有效题目。教材归属会显示在题目上，修改汉字或年级时转为个人题，避免误标官方范围。

**已有用户升级：** 点击课堂提示中的“添加新版教材题库”，或管理器的“补充缺失教材题”。只追加缺失教材题，保留全部已有题目及个人修改，不需恢复默认。首次访问则初始化156道默认题（48道通用题和108道教材题）。

可以导出 JSON 题库备份，在另一台电脑导入。导入会先检查和预览内容，确认后整体替换。恢复默认题库也会移除个人修改，操作前可先导出。

**题库长期保存；课堂分组、得分和答题进度在刷新后重置。** 已开始的一轮使用题目快照，备课修改从下一轮生效。清理浏览器网站数据或使用无痕窗口可能丢失本地题库，请定期导出。跨设备不会自动同步。

## 开发与验证

```powershell
npm test
npx playwright install chromium
npm run test:ui
npm run build
```

`npm run prepare:strokes` 从已安装的源数据重新复制全部131个内置汉字的笔顺和许可文件。浏览器测试使用独立5175端口并自行启动开发服务，避免误用5174上的旧预览。通用题的年级表示建议难度，教材题依据上述固定版本。第三方数据来源及许可见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

设计记录见 `docs/superpowers/specs/`。本地执行日志不纳入公开仓库。课堂使用无需账号、服务器数据库或付费服务。
