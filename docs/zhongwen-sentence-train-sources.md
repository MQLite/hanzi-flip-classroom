# 《中文》句子小火车选句来源

选自使用者提供的暨南大学华文学院编《中文》（小学）第三版（2023）第一、二册扫描PDF，逐页核对课文及阅读栏目。PDF与整页图像不上传网站。页码为教材印刷页；PDF页码=印刷页码+15。

第一册前六课正文以识字图文为主，因此选用对应课次的阅读儿歌、谜语；第7–12课及第二册各课同时选用课文与阅读。短句按自然词块拆为2–7节车厢，每节最多6字，全句最多28字。

优先保留完整原句；诗歌、复句选取连续的短分句时，不增删或改写文字，只将句尾标点统一为句号、问号或感叹号。数据中的 originalText 保存原始出处句，sentence 保存用于练习的连续摘文；notes 说明节选与标点调整，课堂来源旁显示“节选”，悬停可看说明。

选句按教材/册/课独立加载，不占用或改写识字卡及浏览器中的个人题库。现有手工切分句也可继续参与所选课程；同一句仅进入一轮一次。
