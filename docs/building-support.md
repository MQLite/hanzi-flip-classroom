# 汉字建筑师：支撑与局部下落

倒塌由词砖所在的位置与剩余支撑决定，不再预先抽取“危险词”。同一建筑、同一词砖排列和相同拆除顺序，结果总是相同。随机数只影响词语排列、抽读顺序。

## 简化规则

- `building-support.js` 从实际蓝图尺寸、位置计算接触；接触面在水平面的凸包必须覆盖该词砖的重心投影，才有支撑。基础与桥墩也需要接地或接触下方基础，不能凭类型在空中站住。
- 房、塔、楼的词砖逐层传递支撑。下层失稳后，计算继续向上，只有失去支撑的部分下落，独立的稳定部分保留原位。
- 平梁桥、斜拉桥、廊桥的同层相邻词砖视为相连桥面，合并检查其体积加权重心与桥墩接触范围；拆去一段会断开连接，剩下的各段分别检查。拱背桥的每列有实际接地的支墩，支撑弧形桥面，不模拟拱券水平推力。所有桥面词砖仍然一词一砖。
- 屋顶和装饰只由下方实际接触面承托，不能反过来撑住词砖。小幅嵌入和安装间隙允许用于屋顶附件；斜拉杆固定于明确的塔柱。孤立的装饰向下落后收起，不能悬空停留，也避免装饰碎片穿过保留下来的词砖。平面/减少动态效果直接显示收起后的终点。
- 只有另一个词砖失去支撑才进入 `collapsed`。仅装饰落下仍可继续读词。若全部词砖安全拆完，进入 `cleared`，显示“词砖已安全拆完”，可进入下一活动，也可读重点句子复原。
- 状态记录 `fallenIds` 与 `detachedBlockIndices`；平面和立体使用相同的下落集合与终点，切换显示、重新渲染、隐藏页面、减少动态效果或失去 WebGL 上下文都不会重新抽判定。

## 视觉边界

下落只作用于失去支撑的部分：向下加速，水平位移小于 0.2 个场景单位，倾斜小于 0.2 弧度；没有整栋抛射、旋转爆炸或全体摇晃。失稳词砖留在地面供观察；装饰下落后收起，复原时一起回归。已读词砖仍独立移出，句子复原仍使用原有魔法回归动画。

这是课堂积木的确定性视觉模型，不是建筑工程分析。它使用均匀密度、接触几何和逐层重心检查，未计算材料强度、弯矩、摩擦、三维连接破坏、上部荷载的力矩再分配或连续碰撞。下落终点是原位置附近的地面姿态；不求解真实碎块堆叠，因此多个碎块可能重叠。它不应被用于评估真实建筑安全。

支撑范围与重心投影的规则依据静力平衡中净力、净力矩和重力作用点的原则作游戏化简化，参见 [OpenStax《University Physics Volume 1》12.1 Conditions for Static Equilibrium](https://openstax.org/books/university-physics-volume-1/pages/12-1-conditions-for-static-equilibrium)。

## 验证

`tests/building-support.test.js` 覆盖下层拆除、独立立柱保留、多层连锁、跨双墩屋顶、桥面断开、装饰脱落、安全拆完/句子复原，以及四类建筑 × 四个变体 × 1–16 词的初始稳定性。`tests/building-support/ui.spec.js` 检查立体/平面切换、相同状态重新渲染、局部下落姿态、读词控制锁、恢复与下一活动。

原先的随机危险词测试已改为实际支撑损失测试；单词轮次正常结束为 `cleared`，不人为强制造成建筑倒塌。
