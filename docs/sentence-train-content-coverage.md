# 句子小火车题库覆盖审计

核对日期：2026-09-21。

## 范围与方法

本次只为项目已有的 620 道内置题补写人工词语切分，不修改题目的 ID、教材归属、汉字、例词或例句。一个例句同时满足以下条件才纳入：正文只含汉字；句尾只有一个 `。`、`？` 或 `！`；正文不超过 28 个汉字。每条纳入记录再由人工切成 3–7 节自然词语，每节 1–6 个汉字，连接后必须逐字还原原例句。

切分表以完整例句为键，但发布内容只从三个现有内置题数组生成。每条发布记录同时保存原题 ID 和原例句；运行时必须两者都精确匹配。老师手动保存的有效切分优先于内置记录，改过例句的旧题不会误套原切分。不同题目可以共用同一句话；每轮组题仍按完整例句去重。

例句与来源范围沿用仓库已有记录：

- 《汉语乐园》课次、扫描件核对范围及项目配编例句见[《汉语乐园》1A–3B PDF 题库](hanyu-paradise-sources.md)。出版社的[系列页](https://www.blcup.com/SeriesBook/index/1570)仅用于书目信息核对；本次没有从网页或教材正文导入新句子。
- 新版《中文乐园》的 ISBN、官方大纲和项目配编内容边界见[《中文乐园》题库来源与范围](curriculum-sources.md)。
- 通用例句来自项目原有 `src/data.js`。年级字段继续表示建议难度，四年级例句没有被下调或改写。

## 排除说明

当前小火车格式只允许正文中的汉字和一个句末标点，不能表示中间逗号。以下 34 个不同例句因此保留在识字和组词题库中，但不生成内置小火车记录。它们不是因难度或年级被删去。

《汉语乐园》有 21 个不同例句、24 条题目记录。`现在，我们开始做游戏。`、`刮风了，树叶轻轻地动。`、`请问，书店在哪里？`各关联两个题目 ID。

- 带句首时间、地点或话题停顿：`从前，山里住着一只小兔子。`、`早上，我和妈妈一起散步。`、`早上，窗外传来鸟叫声。`、`现在，我们开始做游戏。`、`晚上，我给弟弟讲故事。`、`星期日，我们一起去放风筝。`、`星期六，我们一起去图书馆。`、`当时，我正在画画。`、`春天，小草长出来了。`、`这几幅画里，我最喜欢这一幅。`、`出门前，请穿上外套。`、`冬天出门，我会戴上手套。`、`外面很冷，请穿上外套。`。
- 含两个分句：`对不起，我迟到了。`、`天黑了，我们回去吧。`、`天气不好，我们在家看书。`、`春天到了，花也开了。`、`下雪了，屋顶变白了。`、`刮风了，树叶轻轻地动。`。
- 含问答转折或呼语停顿：`我喜欢画画儿，你呢？`、`请问，书店在哪里？`。

新版《中文乐园》排除 5 个不同例句：`你好，我叫明明。`、`晚上，小村子很宁静。`、`再等五分钟，我们就出发。`、`上课了，请打开课本。`、`早上好，老师！`。前四条分别是两个分句或带句首时间停顿，最后一条含呼语停顿。

通用题排除 8 个不同例句：`下雨了，我们带上雨伞。`、`春天到了，小草变绿了。`、`清晨，鸟儿在枝头唱歌。`、`第一次上台，需要一点勇气。`、`仔细观察，就会有新的发现。`、`遇到难题时，先认真思考。`、`每天朗读，能让表达更加流畅。`、`认真倾听，才能理解别人的想法。`。这些句子包含两个分句，或在时间、条件、主语之后保留必要停顿。

自动测试从三个内置题数组重新计算纳入集合，不只检查固定总数；它要求所有符合上述边界的题目 ID 恰好出现一次、所有切分通过重建校验、两套教材每课及各阶段的不同例句与来源一致，并核对原 72 条记录的完整摘要。
