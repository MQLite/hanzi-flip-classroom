# 汉字数独选词来源

数独以本课“读一读”的生活高频词为优先，同课核心生词可参与。只补入在本课认读/阅读原页核实的自然词或日常短语，不把单独拼音音节、笔画或无法确定汉字的配图算成新词，不跨课凑数。原三个游戏的教材词库不改写。

《中文（暨南大学版）》使用已逐页核对的第一、二册完整词表：24课各9个首选，共216项；22课全部选自认读栏目，第一册第8课和第二册第10课混入同课核心词，说明保存在数据中。没有额外复制已有“读一读”词项。

《汉语乐园》以原1A–3B的核心词表为基础，重新看图核对本课 Learn to read（读一读）。1A、1B认读栏主要为拼音教学，十课在完整本课候选池中仍不足9词；数独明确显示真实数量及换课入口，不从图片反推词汇或借下一课内容。其余分册补入的阅读条目保留原页、原文和原注音依据。PDF页码均从1开始：《汉语乐园》比印刷页多3，《中文》比印刷页多15。
