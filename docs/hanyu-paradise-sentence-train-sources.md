# 《汉语乐园》句子小火车教材选句

依据使用者提供的六册旧版英文版学生用书《汉语乐园》1A–3B扫描PDF，逐页目视核对原字、标点与栏目。文件身份及SHA-256沿用[hanyu-paradise-source-review.json](hanyu-paradise-source-review.json)。PDF与原书整页图片不随网站发布。

选句来自课文对话、歌曲（Let’s sing）与故事（Let’s tell a story），遵循原书课次；单元末歌曲、故事以实际所在课次页段归入，不跨课补齐数量。每条带栏目、篇名、PDF页和印刷页。六册均为PDF页码=印刷页码+3。

不使用识字卡的辅助配编句填充教材小火车。原来的441条《汉语乐园》辅助例句自动映射已移除；识字卡及浏览器保存题目不被覆盖，老师明确保存的有效手工切分仍可练习。新版《中文乐园》与通用题的143条原有映射逐条保持一致；暨南大学版《中文》85句不变。

每句按自然词块分为2–7节，每节1–6字，正文至多28汉字。优先完整原句；从一组气泡或一段歌词中选连续完整短句时，保存 originalText 与 notes。需要规范逗号、引号等标点时，只调整标点，不添字、换字或拼接非连续句段，原标点仍保存在 originalText。

**1A第3课《一、二、三》只有数字认读，没有适合该课的完整短句，因此没有小火车题。** 不借用第4课歌曲，也不补造句子。选择本课时页面说明原因，并引导切换识字翻翻乐或选择其他课。
