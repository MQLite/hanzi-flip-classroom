# Building 3D Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans inline, task by task.

**Goal:** Upgrade the four existing buildings into 3D blocks with clear drop, scattering and flying-back animations.
**Architecture:** Pure block descriptions/motion sampling, persistent Three.js scene with SVG fallback, current view/state integration.
**Tech Stack:** Existing Three.js/Vite/JavaScript/CSS/Vitest/Playwright; no new dependency.
**Spec:** docs/superpowers/specs/2026-11-08-building-3d-design.md.

## Global Constraints

- Four16-part structures; same lesson/reading/challenge/rescue rules and saved banks.
- Animate only visual poses, never advance or restore game state automatically.
- Stable canvas through ordinary renders; no frames when inactive/hidden or settled.
- Reduced motion settles immediately; failed/lost WebGL keeps playable SVG and unlocks controls.
- During visual transitions lock reading/challenge/rescue actions, retain mode/lesson exits and held-key protection.

## Review Focus

- Quick phase changes or stale callbacks must not replay an old transition, duplicate progress or deadlock buttons.
- Word/pinyin refresh and mode snapshots must preserve canvas, poses and reading state.
- Reduced-motion changes, hidden pages and context loss must settle/unlock without timers firing on a new round.
- Four3D silhouettes, shadows and scattering must remain visible in mobile/projector aspect ratios.
- Renderer, observers, frames and model resources must be bounded through repeated rounds/mode toggles.
