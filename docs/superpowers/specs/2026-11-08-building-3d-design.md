# 汉字建筑师：3D积木与明显的搭建、倒塌、复原

用户明确要求四种建筑具有3D效果，搭建时一块块增加，倒塌和复原动画更明显。延续既有网页、游戏规则和上线授权，直接升级建筑视图。

## 方案与范围

沿用网站已有Three.js，制作房、桥、塔、楼的实体积木模型，具有顶面凸点、透视、光照和地面阴影。主场景只保留一个可复用渲染器；准备页的四个小图仍为轻量SVG。相比只改SVG阴影，真实立体模型能够清楚呈现朝不同方向散落和飞回的积木；无需新增依赖、图片或在线服务。

每种建筑分成16个可见积木组，按朗读进度依次落入位置；一次朗读对应多组时错开落下。倒塌先短暂摇晃，再翻转、抛散到地面，并显示尘点；复原让碎块沿弧线飞回，逐块归位。倒塌/复原约1.5–2秒，积木落下每块约0.6秒，足够投屏观察。动画期间暂缓下一步朗读确认，可随时换游戏或课次。

保持当前抽词、教师确认、危险词保密、重点句子解救、独立快照和全部题库规则。动画完全不写分数、句子或游戏状态。没有WebGL、上下文丢失时自动使用原有平面图继续课堂，也提供平面/立体切换。减少动态效果设置直接显示相应静态3D状态。

## 生命周期与验证

普通选词/拼音刷新保留同一canvas和模型，不重播动画。换课/重开清理旧模型；离开游戏或隐藏页面结束当前视觉过渡、停止绘制；回来显示正确最终状态。动画中切换显示、改变减少动态效果或上下文丢失，都解锁操作，不留下旧回调。

验证四种模型与动画的起止姿态、实体块数量、逐步进入、倒塌散落与归位，真实WebGL画面变化、静态/平面降级、键盘和手机、画布复用、隐藏/切换/重开边界、无题库变化；回归既有建筑、女巫和其他模式，完整单元测试、生产构建、独立复核、上线验证。
