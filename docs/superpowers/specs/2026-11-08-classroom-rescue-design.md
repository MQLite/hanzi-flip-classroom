# 本课句子解救与汉字建筑师

用户在女巫游戏上线前追加：中毒后可选择解药环节，读出本课重点句子解救该同学，之后可换课；完成此改动后，继续制作并上线建筑游戏。沿用已授权的网页、教材和部署方式，按上述顺序执行。

## 解药（先完成并上线）

任一毒药仍立即结束读词并展示变身，不记录出局。结束页可选“使用解药”：显示开局时选择的本课重点句子及教材出处，学生朗读后由老师点击“读完了，解救成功”，恢复笑脸。也可以跳过，直接换小女巫或选择其他课。下一轮重置解救状态。

准备页允许选择本课解药句子或不用解药。句子使用现有《汉语乐园》《中文》课本句子库，严格限定本课；个人/其他题库使用其现有本课例句，不编造教材句子。缺句时提示并保留可玩的读词流程。

## 汉字建筑师（随后制作并上线）

每课可选房、桥、塔、楼，选择本课1–16个生字/词语（默认最多12个），选择本课拯救句子。点击抽词，学生朗读，老师确认后增加一部分建筑，直至搭建完成。每词只建一次，重复确认不增加进度。

搭建完成后可进入随机读词挑战。抽词与老师检查分两步；系统从本轮词卡中随机指定一个危险词，不在公开界面暴露。读到它并确认后建筑倒塌，立即停止抽词。展示本课拯救句子，学生朗读后老师点击复原，全部建筑恢复；可再挑战、重新搭建或选择其他课。

实现方决定：无语音识别、倒计时和学生名单；危险词每次挑战重新随机指定；使用原生SVG绘制四种建筑，逐步点亮部件，倒塌及复原使用CSS动效并遵循减少动态效果。没有可用重点句子的课仍可搭建，提示补充句子后再开启倒塌挑战，避免无法解救。

## 约束与方案

沿用现有JS/CSS、单课词库、游戏切换快照和教师教材选择器，无新服务或依赖，不写题库或学生数据。原七项游戏、题库修改和个人数据保留。四种建筑共用一套朗读/挑战状态机和独立SVG图形，避免四套规则不一致。自动语音判分和自由拖砌不在本次明确要求内，采用与已有游戏一致的教师确认操作。

解药是女巫现有结束页的可选后续，不改变任一毒药结束本轮和所有同学下一轮参加的规则。更换课次重新准备，游戏切换保留本页各自进度。

验证本课句子来源、空句降级、可选/跳过/解救/下一轮、建筑四种外形、逐词幂等、随机危险词、倒塌后禁止继续、句子复原、换课隔离、快照、题库不变、键盘/触屏/手机/投屏和已有游戏回归。
