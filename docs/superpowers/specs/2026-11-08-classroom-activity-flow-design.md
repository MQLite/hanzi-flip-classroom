# 本课三项活动衔接

用户在3D建筑升级过程中明确追加三项任务，并要求依次完成：建筑自由选字挑战；女巫逐词即时反馈及解药选择；汉字迷宫。保留已经完成的3D与既有题库。教师负责确认口头朗读，不引入语音识别服务。

## 任务1：建筑词卡挑选

搭建仍为抽词、朗读、教师确认、逐块增加3D积木。建好后右侧直接展示本轮全部词卡，学生自由选词朗读，教师点击已读词卡立即检查；安全词卡消失，危险词触发倒塌。每轮危险词随机、提前保密，已收走卡不可重复选择。读出本课拯救句子、确认复原后，可进入下一活动“女巫的毒药”。没有本课句子的数字课仍可搭建并继续下一活动。

## 任务2：女巫即时中毒

保留闭眼秘密选择1–2个毒药。读词阶段教师点击学生读过的词卡即产生结果，不再要求额外揭晓按钮，也不等待其他词。毒药立即显示烟雾/变身和轻松卡通音效，结束该轮；随后突出显示“需要解药吗？”的使用/跳过选项。有解药时显示选定的本课重点句子，朗读并确认后恢复；跳过、无句子或解救后均能进入“汉字迷宫”。音效可关闭，WebAudio不可用则安静继续。音效只在首次中毒/首次解救触发，切换/后台立即停止。

## 任务3：汉字迷宫

使用当前教材单课生字，9×9可观察迷宫，起点、出口、墙和岔路清楚可见，至少有两个死路。上下左右选择相邻可走格子，先认读格中汉字，再由教师确认前进；未确认/需重读不会移动，不能穿墙、跳格。死路可以退回重读，观察路径寻找出口。每步使用本课字，必要时重复分布，不混入其他课。空词库提示换课/题库管理。支持拼音、触屏与键盘，出口完成后可换课重新开始本课三项活动。

## 衔接与约束

新增紧凑活动导航“搭建挑战 → 女巫毒药 → 汉字迷宫”。活动结束按钮携带当前教材、册次、课次、个人题库年级，目标活动重新准备同课内容；原游戏导航继续保留各自本页快照。进行中主动换活动可使用已有放弃进度确认，结束后无需重复确认。现有所有游戏、教材和个人题库数据保留，不新增云存储或学生身份数据。

验证安全词消失/危险词即时倒塌、重复点击、逐词中毒/弹出解药/音效与静音、迷宫出口连通与死路/相邻和认读门槛、同课衔接和快照、设备/键盘/减少动态效果、原有游戏回归；最后独立复核并统一发布。
