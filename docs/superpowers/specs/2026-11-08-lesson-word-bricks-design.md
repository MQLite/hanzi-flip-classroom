# 逐词拆砖与每课新外形

用户要求在对应砖上显示汉字，搭好后每认读一个词就消失一块砖；房、桥、塔、楼的外形和迷宫布局随课次变化，保留既有课堂活动衔接。

直接在现有Three.js游戏中实现。每个选词对应一块正面可读的词砖，基础/屋顶/桥柱等作为建筑装饰。搭建确认逐块增加词砖，最后搭完整外形；挑战点选右侧已读词卡，安全词砖移出并消失，危险词触发剩余建筑倒塌；句子拯救复原全部词砖，重新挑战清空检查记录。教师确认/选卡继续作为认读判断，无新增语音识别。

每类建筑采用四种有几何差异的外形，由教材、册次和课次选择，邻课切换款式。不同轮次和拼音开关不改变本课外形。采用固定课次款式而非每次刷新随机，便于课堂讲解；纯配色变化不足以满足外形要求。文字纹理贴在砖面，长词自动换行；平面回退使用同一蓝图、相同词砖和移除规则，输入文本安全写入。

迷宫仍是9×9、相邻读字、教师确认、3D行走和出口庆祝；课次参与生成，并用入口内侧首段通路的奇偶差异保证邻课路线不相同。同课重开排除上一张网格。每张保持所有可走格连通、至少两条非出口死路和可达出口。无持久化题库/存储格式变化，无新依赖。

验证1–16个词的对应关系、实际砖面文字与消失画面、快速输入锁、半途切换/重开/减少动态/上下文丢失、倒塌后完整复原及再次挑战、四类四款几何/相机范围、课次和重开迷宫差异、手机及投屏、原活动衔接和个人题库不变。使用现有隔离工作区，单次最终独立审查；发布前完成可预览结果并获得本次线上更新授权。
