# 汉字奇遇岛：识字翻翻乐设计

## 目标与范围

为小学一至四年级汉语老师制作课堂投屏网页。老师操作，全班通过口头抢答参与。第一版只实现“识字翻翻乐”；组词工坊、句子小火车不在本次实现范围内。

核心是认字、读音、组词和例句，以及 3D 翻牌、教师控场和分组计分。笔画、笔顺、偏旁部首是按需展开的附加学习内容，不改变答题流程，不占据主画面，不成为必答题。

第一版包含教师题库管理：新增、修改、删除题目，本地自动保存，题库文件导入导出，以及恢复默认题库。题库管理作为备课入口，不占据课堂主操作区。

## 课堂流程

1. 老师选择一至四年级中的一个年级，开始一轮游戏。
2. 主画面展示一张大尺寸汉字卡片，学生口头回答读音或组词。老师可以选择显示拼音提示。
3. 老师点击“翻牌揭晓”，卡片通过 3D 翻转展示拼音、常用组词和简短例句。
4. 老师选中作答小组，点击“答对了”为该组加一分，或点击“再练一次”将该字加入本轮复习列表。每张卡片只允许结算一次，避免重复点击加分。
5. 点击“下一字”继续。完成本轮后展示各组得分，以及需要再练习的字；可以开始复习或开始新一轮。

第一轮默认八个字，抽取不重复；同一汉字的不同读音题在同轮中只选一道。该年级可用汉字不足八个时使用实际数量，并在开局前说明；没有题目时提供添加题目或恢复默认题库的入口，不开始空轮次。支持上一字回看，回看不重复计分。默认两个小组，可在开局前改为二至四组并修改组名。切换年级或重新开始时，如已有本轮进度，提示会重置本轮进度，允许取消。

## 教学内容

内置四档示例题库，每档至少十二个经过核对的汉字。年级划分作为教学难度建议，不声称与某个教材版本逐课对应。各档适用原则：

- 一二年级：常用字、易理解的组词及短句，拼音提示默认打开。
- 三四年级：逐步加入形近字、多音字语境和更丰富的组词，拼音提示默认关闭。

每条题目包含汉字、带声调拼音、两个常见组词、一个例句。多音字明确本题读音及其语境，不把其他正确读音判为错误。由教师判断口头作答，不提供语音识别或自动判分。

## 教师题库管理

在“题库管理”中按年级筛选、搜索汉字，新增、编辑或删除题目。首次使用时将内置题库复制为可编辑的个人题库，内置原始数据始终保留。

可编辑字段包括：年级（一至四年级）、单个汉字、带声调拼音、两个组词、一个例句，以及可选的笔画数、部首、常见偏旁说明和字形结构。核心字段必填；笔画数如填写须为正整数。新增或修改后进行完整校验，合格的题目自动保存，界面明确显示“已保存”或具体错误。尚未填写完整的新增题目及未通过校验的修改保留为当前编辑草稿，不进入游戏，也不覆盖上次有效版本；离开未保存的草稿时提示。

每道题使用稳定且唯一的 ID。相同年级、汉字和读音的重复题目不允许保存；同一个汉字的不同读音可分别建题，并填写相应组词和例句。校验负责格式和完整性，教师自编内容的教学准确性由教师核对，不把格式校验表述为内容审核。

修改汉字后清除原字的笔画数、部首、偏旁说明、字形结构与笔顺关联，按新字重新匹配可信的本地数据；未匹配到的可编辑扩展字段留空供老师补充。笔顺动画不能由普通文本编辑自动生成，也不开放任意动画代码或矢量脚本输入。笔画数与已有笔顺数据不一致时提示老师检查，不显示相互矛盾的笔画数和动画。

课堂开始时对所选题目及其内容建立本轮快照。编辑、删除、导入或恢复题库都只影响后续新轮次，当前轮次及其复习继续使用原快照，防止教学中途答案变化或题目消失。

## 题库持久化与备份

个人题库使用浏览器本地存储持久化，每次有效编辑后自动写入。刷新、关闭页面或关闭浏览器后，在同一设备、同一浏览器配置及同一网站地址重新打开，仍能读取题库。仅在从未建立个人题库时初始化默认数据；主动清空的个人题库保持为空，不在重启时自动补回默认题目。

题库数据带格式版本号，便于后续升级。第一版采用 localStorage 保存小规模文本题库，笔顺资源独立随应用提供，不重复写入题库。启动方式应提供固定的网站地址，保证持久化归属稳定；不依赖直接打开本地 HTML 文件时浏览器不一致的存储行为。

题库与课堂状态分开：题库长期保存；分组名称、得分、当前题目和复习列表仅在当前页面会话中保留，刷新后重新开始。页面说明明确区分“题库已保存”和“课堂进度不自动恢复”。

本地保存不提供跨设备自动同步。清理网站数据、更换浏览器、使用无痕窗口或更换访问地址可能导致原题库不可见或丢失，因此提供：

- **导出题库**：下载带格式版本号的 JSON 文件，包含个人题库的全部题目、唯一 ID 和可编辑扩展字段。文件名包含日期，便于备份和传给其他老师；不包含课堂得分或编辑草稿。笔顺动画按汉字匹配应用自带数据，不随题库文件重复导出。
- **导入题库**：第一版采用整体替换方式。先读取并校验整个文件，展示各年级题目数量、总数及将替换现有题库的说明，提供先导出现有题库的入口，确认后一次性替换。取消、格式错误、不支持的版本、缺少字段或重复 ID／重复题目均不改变原题库；展示可定位到题目的错误。允许有效的空题库文件，预览明确显示零题。
- **恢复默认题库**：提示将移除个人修改，并提供先导出的入口，确认后以完整内置题库替换个人题库。该操作不改变已开始的课堂轮次。

导入仅接受符合数据结构的文本字段，不执行文件内的代码或将题目内容作为 HTML 渲染。导入、恢复默认和有效编辑均在本地写入成功后才显示保存成功；写入失败时保留上次成功保存的版本及当前待保存内容，提示重试或导出备份，不悄悄丢弃修改。启动读取失败或发现损坏数据时，不自动覆盖原始存储；提供重试、下载原始备份以及确认后恢复默认题库的入口。

## 附加学习内容

揭晓答案后提供次级入口“拓展学习”，默认收起。展开后可以查看：

- 总笔画数和笔顺演示；支持逐笔查看、播放和重播。
- 部首、常见偏旁说明及字形结构；避免将偏旁和检字部首混为同一概念。
- 在有准确字形区域数据时突出显示相应部件。

笔顺采用经过核对且授权允许使用的矢量数据，不用字体笔画猜测笔顺。实现时记录数据来源及许可；随应用提供本地资源。某字缺少可靠演示数据时，保留准确的笔画数及部首文字说明，并明确显示“暂无笔顺演示”，不显示伪造动画。附加内容不会影响主游戏继续进行。

## 视觉与交互

采用明亮、清晰的儿童课堂风格，以汉字卡片为视觉中心。背景使用轻量立体场景和柔和装饰，文字区域保证对比度。卡片具备立体厚度、悬浮阴影和真实空间翻转；答对后出现短暂星星奖励，避免持续动画分散注意力。

针对 16:9 投屏优化，汉字、答案和主操作保持大尺寸。小屏幕下重新排列控制区，避免遮挡。翻牌后的汉字和笔顺演示保持正面展示，避免透视影响识读。

提供全屏、拼音提示开关和简明键盘说明。空格翻牌，左右方向键切换已访问的上一字或继续下一字；输入组名时快捷键不生效。未结算便跳到下一字时，将该字记为未作答，不自动判错或给分。遵循减少动态效果偏好，在该模式下缩短或取消翻转及奖励动画。

题库管理使用独立面板，清楚显示编辑、保存及导入预览状态。打开该面板或在任何表单字段输入时，课堂翻牌和切题快捷键暂停，避免编辑文本触发课堂操作。

## 实现结构与状态

独立前端网页，无需账号和后端。主 3D 效果采用 Three.js WebGLRenderer：立体卡片、光影、轻量场景与星星奖励。教学文字、控制按钮和编辑表单采用 HTML，笔顺采用 SVG；文字可通过与卡片同步的 CSS 变换保持清晰。提供简化显示开关，WebGL 初始化失败时自动使用 CSS 翻牌，主游戏不依赖渲染器成功。依赖本地打包，不在课堂运行时依赖外部 CDN。

控制场景复杂度、像素比和阴影开销，页面不可见时暂停渲染；调整窗口或全屏时更新画布尺寸。减少动态效果模式关闭持续漂浮与粒子特效。浏览器失去 WebGL 上下文时切换简化显示，不重置课堂状态。

- 题库模块：汉字、拼音、组词、例句及扩展数据引用。
- 题库管理模块：筛选、搜索、新增、编辑、删除、内容校验及草稿状态。
- 存储模块：版本化的个人题库、本地读写、导入导出、恢复默认及存储故障处理。
- 游戏状态模块：年级、轮次、题目顺序、当前题目、揭晓状态、判定记录、分组得分和复习列表。
- 界面模块：年级选择、立体卡片、答题控制、计分栏、轮次总结。
- 扩展学习模块：部首说明、笔画信息和笔顺播放，不干扰主流程状态。

计分从本轮判定记录推导，回看和重复点击不会累计分数。题库、持久化存储与界面分离，默认题库和个人题库分别管理。轮次状态引用开局时的题目快照，不直接引用可编辑题库；仅课堂进度在刷新页面后重新开始，个人题库从本地存储恢复。

## 异常与可访问性

浏览器不支持全屏时给出简短提示，普通页面仍可游戏。缺失扩展数据只影响相应扩展区域。按钮具备明确名称、键盘焦点和禁用状态；动画期间避免重复操作造成状态错乱。所有结果同时使用文字反馈，不只依靠颜色或声音。

## 验收与验证

验证完整流程：选择年级、翻牌、加分、重复点击、上一题回看、再练一次、切换年级、轮次完成及复习。重点验证重复加分防护、复习列表去重、题目不重复，以及扩展面板不会影响答题和计分。

验证题库新增、编辑、删除、年级筛选和搜索；确认无效草稿不污染有效题目。验证修改汉字后不会沿用旧字的笔顺及部首数据。验证同一汉字不同读音的题目能保存但同轮不重复出现，以及题库少于八字、某年级无题和题库全部清空时的行为。

验证修改后刷新及关闭重开仍保留题库，课堂进度按约定重置。验证导出再导入后的内容一致；取消导入、格式或版本错误、重复题目及写入失败均保留原题库。验证恢复默认前的提示及取消路径，存储不可用、额度不足和损坏数据时的故障处理，以及备份导出能力。确认课堂中修改题库不会改变当前轮次与复习的题目快照。

在浏览器中检查投屏尺寸及较窄窗口，确认汉字不裁切、操作可达、3D 正反面正常、全屏及键盘可用。逐条核对示例题目与显示数据，对具备笔顺演示的汉字核对笔画数量与顺序。交付包含可运行源文件、启动说明和实际验证结果。
