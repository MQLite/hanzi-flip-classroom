# 女巫的毒药：闭眼藏毒与轮流读词

状态：用户已确认流程并要求加入网站：“中毒的同学本轮出局，下一轮再参加。就按这个流程，把‘女巫的毒药’加到网站里。”直接实施，不再次请求玩法确认。

## 已确认玩法

准备本课词卡 → 其他同学闭眼 → 一位小女巫秘密选择1–2张毒药词 → 藏好后清除选择标记 → 大家睁眼并轮流选词、读词 → 老师点击揭晓 → 安全卡变灰，中毒的朗读者本轮出局 → 下一轮所有学生恢复。

读错先纠正并重读，再正常揭晓；中毒由预先选定的毒药卡决定，不代表中文答错。

## 实现方确定的细节

- 新增“女巫的毒药”独立入口，保留现在的识字、组词、小火车、数独、情景探索和打地鼠。
- 沿用单课生字/词语来源，优先词语，允许单字；复用当前打地鼠的已核对单课词库。现代教材的辅助例词仍如实标注；无拼音的词不编造拼音。
- 开局前可选2–16张卡，默认最多12张；必须至少有一张安全卡。教师选择1或2个毒药。
- 可编辑2–30位学生姓名，默认6个编号；选一位当小女巫。本轮小女巫负责藏毒，不参加朗读。
- 自动按名单轮流安排仍在场的朗读者；老师可在尚未选词时调整当前朗读者。选词不会立即揭晓，须按“读完了，揭晓”。
- 一轮在全部毒药被发现、卡片用尽或全部朗读者出局时结束。结束后显示本轮结果和“下一轮”，下一轮清除出局、已读卡和毒药，轮换小女巫，保留学生名单和所选词语。
- 不为随机中毒扣认读分，不新增学生云记录。每个已揭晓卡只结算一次，出局者不能再次朗读。
- 独立保存本页设置和进度，刷新重置；题库保存格式不变。

## 藏毒隐私与操作

状态依次为 cover（闭眼遮挡）、hide（秘密选毒）、ready（已藏好，可睁眼）、read（选词再揭晓）、complete。

只有 hide 阶段呈现毒药选择标记。ready/read 不将未揭晓毒药写入卡片样式、属性或无障碍名称。读词阶段只显示已揭晓结果。

切换游戏、切到后台、从藏毒界面打开帮助或题库时，先返回遮挡状态；恢复后须再次提示其他人闭眼，不能把秘密选择直接展示给全班。已藏好后可正常保留轮流读词进度。

不引入语音识别，由老师判断学生已读完。鼠标、触屏和原生键盘按钮均可操作。文字适应词长，不溢出卡片；手机卡片换行，不造成页面横向溢出。
