# 汉字迷宫：3D小人逐字前进与出口庆祝

用户明确要求将现有汉字迷宫升级为3D，小人随着读字一步步移动，抵达出口有庆祝动画。沿用已授权的网站实现与发布方式，不再次确认已明确的玩法。

采用现有Three.js渲染立体迷宫墙、地面、入口旗、出口拱门和卡通小人。汉字仍为清晰的原生DOM文字/按钮，投影到对应地面格，支持鼠标、触屏和键盘。保留9×9现有生成、同课字库、死路、相邻选择与教师确认规则。动画不修改游戏状态或题库。

只有老师确认认读后小人才走一格，约0.62秒，有转向、迈腿和轻微起伏；选字/重读不会移动。行走期间暂缓新的认读动作，模式/重开仍可离开。走到出口后再跳跃挥手、亮起出口并飞出彩纸，约1.8秒，庆祝结束可进入下一课。普通拼音刷新不重播移动或奖励。

保留同一canvas和模型资源；新迷宫重建布局，换游戏/后台/重开时结束视觉过渡并停止帧循环，返回显示正确位置。减少动态效果时直接显示静态3D位置和完成结果。无WebGL或上下文丢失时自动回到现有平面迷宫，进度与按钮继续可用，也可主动切换平面/立体。

验证相邻移动的真实画面、未确认不走、走完再庆祝、完成奖励只触发一次、画布复用、隐藏/切换/重开/上下文/偏好边界、手机和投屏字迹与相机范围、原活动衔接和题库不变。无新音效、依赖、服务或存储格式。
