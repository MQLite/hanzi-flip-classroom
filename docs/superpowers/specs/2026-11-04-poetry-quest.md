# 古诗书房闯关游戏

用户已确认在现有 GitHub Pages 课堂站点制作原创解谜闯关游戏。以《游子吟》《回乡偶书》为课堂内容，故事为原创虚构，不作为诗人史实介绍。

采用独立的 `quest.html` 页面，首页增加入口，保留现有四种课堂模式。原方案为旧屋中的两封信：观察衣柜、书桌、镜子、门口，收集线索，最后把两封信送到对应位置。针线与家书为一条分支，旧镜与归乡为另一条分支，共五次完成事件。

学习目标是字形与语境、诗句含义、人物视角和寻找文字依据。带提示模式提供读音与词义；独立挑战增加证据选择。答错可调整，分步提示可随时查看，不设置倒计时或惩罚。结尾可以看完整古诗并自愿背诵，不使用自动语音评分。

视觉为原创手绘旧书房、暖纸色、墨绿与铜色。所有可点击物件同时提供可聚焦按钮；支持手机点击、键盘、减少动态效果和无WebGL设备。进度仅保存在独立浏览器存储键，不读取或改变原站题库。可继续旧进度或经确认重新开始。

实现中不引入新运行依赖。Vite多页面构建，GitHub Pages原有基础路径保持有效。需验证两条分支、挑战证据、重复操作、损坏及被禁用的存储、手机布局、完整通关与原站入口。单元测试与构建通过后，按用户指定地址发布。
