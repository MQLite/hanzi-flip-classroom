## 课次与来源字段

`src/paradise-content.js`是可直接维护的数据源：`PARADISE_CONTENT`保存每课的`stage`、`book`、`lesson`、`title`、`pdfStartPage`、`vocabulary`、`writingCharacters`和按课的`examples`。每个词条附`word`、按音节分隔的`pinyin`和`pdfPage`。页码均从PDF第一页起算，不是印刷页码；当前扫描PDF页码比印刷页码大3。

1A前三课写字栏目只教笔画，`writingCharacters`留空，另以`writingStrokes`记录；不会把笔画冒充教材汉字。每课词汇汉字仍参与识字练习。

`docs/hanyu-paradise-source-review.json`记录源文件名、页数、SHA-256及核对说明，可确认以后使用的PDF是否相同。六册扫描图和PDF全文不随网页分发。

## 参考词、句子与读音

每个字的两项参考词优先采用本课核心词汇，余项补入自然的常用词或短语；例句由项目配编，不声称为教材原句，也不保证其中每个字均已学过。老师可按课堂进度修改。代词、助词、数词等允许用自然短语，例如“我的”“是吗”“三个”，符合工坊2–8汉字答案格式。

单字提示采用本调；词汇拼音保留轻声、儿化。子zǐ、睛jīng、朵duǒ等在词中可读轻声；吗ma、呢ne、的de、么me、们men保留轻声。原书“谁”用shuí。儿化词中的“儿”与单字ér区分，独立的“儿”题用“儿童、儿歌”。

多音字按课处理：1A第5课“发”fà（头发），1B第8课“发”fā（沙发）；2B第8课及3A第4课“乐”yuè（音乐），其他出现的“乐”lè；3B第8课“觉”jiào（睡觉），3B第7课“数”shù（数学），1A第6课“长”cháng（长短）。3A词表将语气助词“了”标成liǎo，已依据本课正文更正为le。暖和中的“和”在词汇标huo；独立“和”题使用hé，配“和好、和平”。

笔顺由已安装的`hanzi-writer-data`提供，通过`npm run prepare:strokes`复制到本地，不从扫描图猜测。

## 新旧题库兼容

新题库ID为`hanyu-paradise-ab`；旧数据里的`chinese-paradise-2023`仍只指新版《中文乐园》，不重写归属。1–3为级别，A/B为原书分册，课次为1–12；不能把旧版课题放进新版课程。

首次访问默认选《汉语乐园》。已有本地题库不自动覆盖，点击“补充教材题库”或“补充缺失教材题”追加两版缺失题目；按教材ID、级别、课次、汉字去重，保留已有题目ID及老师修改，重复点击不增加重复题。课堂补充完成后选择《汉语乐园》，刷新后有该题库也默认选它。手动删除的题目只有再次主动补充时才恢复。

备份仍为schemaVersion=1；新旧教材均通过真实课程字表验证。累计练习只跨当前教材的前册前课，不混入另一版。两种游戏共用题库及相同筛选规则。
